# SHERQ_ONLINE_FIRE-EXTINGUISHER

This application is part of the Reginald SHERQ Services project.

## Project Setup Instructions

To run this project from a fresh environment, follow these steps:

1. **Clone the Repository**
   `git clone https://github.com/BritneyReginald/Sherqonilne.git`
   `cd Sherqonilne`

2. **Switch to the Correct Branch**
   `git checkout sherq_online_fire`

3. **Create a Virtual Environment**
   `python3 -m venv venv`

4. **Activate the Environment**
   - On macOS/Linux: `source venv/bin/activate`
   - On Windows: `venv\Scripts\activate`

5. **Install Dependencies**
   `pip install -r requirements.txt`

6. **Run the Application**
   `python3 app.py`
